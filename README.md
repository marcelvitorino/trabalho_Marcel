# 🚧 Zip Aluguel – Plataforma de Locação de Ferramentas

## 📌 Sobre o Projeto

O **Zip Aluguel** é uma aplicação web desenvolvida com o objetivo de facilitar a locação de ferramentas para construção civil, permitindo que clientes solicitem orçamentos de forma rápida e automatizada.

O sistema foi construído utilizando ferramentas no-code/low-code, integradas com automações e inteligência artificial para processamento de dados.

---

## 🎯 Objetivo

Criar uma solução digital para:

- Captar clientes online
- Automatizar o processo de orçamento
- Organizar dados comerciais
- Melhorar o atendimento ao cliente

---

## 👥 Público-Alvo

- Profissionais da construção civil
- Pequenas construtoras
- Clientes em reforma residencial

---

## 🛠️ Tecnologias Utilizadas

- **Webflow** → Construção do site (interface)
- **Make (Integromat)** → Automação de processos
- **Google Sheets** → Armazenamento de dados
- **ChatGPT (Agente IA)** → Processamento de orçamentos
- **HTML, CSS e JavaScript** → Customizações

---

## ⚙️ Funcionamento do Sistema

1. O usuário acessa o site e preenche o formulário
2. Os dados são enviados automaticamente para o Make
3. Um agente de IA processa as informações com base na tabela de preços
4. Os dados são armazenados no Google Sheets
5. Um orçamento é gerado automaticamente
6. O cliente recebe o orçamento por e-mail

---

## 🔐 Segurança de Dados

- Dados sensíveis são mascarados (ex: CPF)
- Processamento seguro das informações
- Armazenamento organizado em planilha

---
